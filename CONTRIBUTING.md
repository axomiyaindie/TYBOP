# Contributing to TYBOP

Thank you for helping people get their businesses online!

## Ways to contribute

- **Write or improve a chapter** in `docs/`
- **Add a template** in `templates/`
- **Fix typos, broken links, outdated info**
- **Translate** a chapter (add `docs/<lang>/`)
- **Share a real story**: what worked, what didn't

## How to submit a change

1. Fork the repo
2. Create a branch: `git checkout -b improve-chapter-04`
3. Make your changes
4. Commit: `git commit -m "Improve domain buying section"`
5. Push and open a Pull Request

## Writing style

- Short sentences, plain words
- Start each chapter with **"What you'll get"**, end with **"Do this today"**
- Explain *why*, not only *how*
- Mention free or low-cost options first
- Don't promote a tool you haven't used; say when a link is an affiliate

## Chapter template

Copy `templates/chapter-template.md` to start a new page.
